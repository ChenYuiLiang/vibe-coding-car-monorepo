1. 从上到下點 GitHub（或本機 `~/Documents/Vibe-Coding-Classroom/<repo名>`）  
2. 照該 repo **README** 測  
3. 有問題就改碼 → 再測 → 結果欄打勾  
4. Classroom push 若規定需避免 CI，commit message 加 `[skip ci]`
