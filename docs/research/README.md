## 📑 發表論文完整清單 (Full Papers)

### 1. SSIM 2026 Paper #27 (CMT ID: 18)
* **論文名稱**：**Full-Stack Vibe Coding Pedagogy for IoT Hardware–Software Integration: A Monorepo Architecture and Hardware-in-the-Loop Verification Study**
* **中文名稱**：《全棧 Vibe Coding 如何支撐手機遙控器與 ESP32 韌體之實作與測試：Monorepo、共享協定與 Hardware-in-the-Loop 閉環研究》
* **核心貢獻**：
  * 提出前後端 Turborepo Monorepo 架構，透過 `packages/protocol` 強制型別安全，根除 AI「協定幻覺 (Protocol Hallucination)」。
  * 實踐 68% 封包瘦身 (Packet Slimming，46B $\to$ 15B 二進位 TypedArray)。
  * 提出 Hardware-in-the-Loop (HIL) 實機閉環驗證與三大非偽造實機產物。

### 2. SSIM 2026 Paper #28 (CMT ID: 19)
* **論文名稱**：**Vibe Coding Pedagogy: A Teaching Framework Design Study Centered on Vibe Classroom**
* **中文名稱**：《Vibe Coding 教學法：以 Vibe Classroom 為核心之教學架構設計研究》
* **核心貢獻**：
  * 提出專為初學者與 K-9 設計的 **PACE 教學框架** (Prompt Design, Audit, Commit, Evaluate)。
  * 建立 **Vibe Classroom 平台** (基於 GitHub Classroom 與 Actions 自動評分)。
  * 提出 **雙層 Tutor 輔導制度 (Two-Tier Tutor Model)**，並於陽明山苗圃童軍營地完成實證。
  * 量化實證：程式焦慮降低 31.4%、程式自我效能感提升 26.8% ($d=0.92$)。
* **文件檔案**：
  * 📄 **Springer SIST 英文全文**：[`SSIM2026_Paper_28_Vibe_Coding_Pedagogy_PACE.md`](./SSIM2026_Paper_28_Vibe_Coding_Pedagogy_PACE.md) ｜ [`SSIM2026_Paper_28_Vibe_Coding_Pedagogy_PACE.docx`](./SSIM2026_Paper_28_Vibe_Coding_Pedagogy_PACE.docx)
