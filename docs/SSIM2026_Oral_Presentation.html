Section 1: The Problem & Context (Paper 28)
The Core Problem: The Cyber-Physical Chasm
1. Syntax Gatekeeping
Novices spend >70% of working memory wrestling with low-level C/C++ compiler errors, pointer arithmetic, register configs, and interrupt flags.
2. Cognitive Overload (CLT)
Extraneous cognitive load suffocates the working memory required for high-order system architecture, kinematic intuition, and creative design (Sweller, 1988).
3. Acute Programming Anxiety
Repeated compilation failures and burned hardware trigger acute Programming Anxiety (PAS), leading to learned helplessness and high dropout rates.
Section 1: The Problem & Context (Papers 27 & 28)
Paradigm Shift: Vibe Coding & The "Protocol Hallucination" Trap
The Promise: Vibe Coding (Karpathy, 2025)

• Natural-language human-AI intent orchestration.

• Rapid synthesis of full-stack prototypes in minutes.

• Removes low-level syntax barriers, empowering learners to focus on system design.

The Trap: Protocol Hallucination in IoT

• AI produces code that "looks correct" and compiles, but catastrophically fails on hardware.

• Schema Mismatches: Web app sends JSON while firmware expects 4-byte binary structs.

• Hardware Blindness: AI assigns strapping pins (GPIO 2/8/9) or omits watchdog timers.

Section 2: Pedagogical Innovation (Paper 28 Core)
Pedagogical Framework: The 4-Stage PACE Model
P - Prompt Design
Role-Task-Constraint structure. Specify hardware pin reservations, non-blocking requirements, and packet schemas explicitly.
A - Code Audit
Critical peer and automated code review. Ban blocking delay(); inspect strapping pins; verify 500ms heartbeat safeguards.
C - Micro-Commit
Fine-grained Git commits with mandatory provenance tags: [AI-Generated], [Human-Modified], and rationale logs.
E - Dual Evaluation
Layer 1: CI automated linting and contract unit tests. Layer 2: Hardware-in-the-Loop physical track verification.

Section 3: Engineering Architecture (Paper 27 Core)
Full-Stack Monorepo Architecture: Single Source of Truth
Heterogeneous Monorepo
Turborepo + pnpm managing both apps/web-controller (HTML5/Web BLE) and apps/esp32-c3 (PlatformIO C++ firmware) in one unified repository.
Shared Protocol (packages/protocol)
Single Source of Truth. TypeScript & C header bindings share packet schemas. Any field alteration immediately forces compile check across both ends.
68% Packet Slimming
Verbose 46-byte JSON compressed into compact 15-byte binary TypedArray. Reduces transmission latency to <15ms at 50Hz control frequency.
Section 3: Engineering Architecture (Paper 27 Core)
Physical Safeguards: Triple Fail-Safe Architecture
1. 500ms Watchdog Emergency Stop
Vehicles listen for 50Hz heartbeat packets. If connection is lost for >= 500ms, firmware instantly cuts PWM to 0, preventing runaway crashes.
2. Dual-Mode Wi-Fi Self-Healing
Operates in STA mode. If router connection drops for >= 8 seconds, the vehicle automatically spawns emergency SoftAP (vibe123456) for recovery.
3. 20s Delayed-Commit OTA Rollback
Over-The-Air updates require active confirmation within 20 seconds. If new firmware crashes or hangs, hardware automatically rolls back to safe partition.

Section 6: Synthesis & Takeaways (Both Papers)
Conclusion & Key Engineering Takeaways
1. Vibe Coding is Not "Code-Free"
It elevates the human from syntax typist to Chief Engineering Auditor. Critical code auditing is the core competency of the AI era.
2. Shared Contracts Eradicate Drift
In cross-platform IoT, Monorepo shared packages (packages/protocol) provide the Single Source of Truth, making protocol hallucination structurally impossible.
3. Safety-First Engineering
Physical AI demands hardware-enforced fail-safes: 500ms Watchdogs, self-healing networks, and HIL verification are non-negotiable.
4. Open-Source Commitment
Our entire 45-unit curriculum, Monorepo codebase, and 3D schematics are fully open-sourced for the global academic community.
