| **中文概要<br>(限500字)** | 本課程為全棧式實體人工智慧（Physical AI）與物聯網軟硬體虛實整合之入門與實作課程。因應生成式 AI 與智慧載具發展趨勢，課程導入產業前沿之「Vibe Coding（自然語言提示協同開發）」模式，以開放原始碼智慧自走車為實體載具，引導學生跨越傳統微控制器與嵌入式硬體開發之底層語法門檻。<br><br>課程內容依四大循序漸進階段開展：(1) 開發環境建置與 ESP32-C3 核心架構；(2) Web 藍牙（Web BLE）控制介面開發與雙輪差速運動學控制；(3) 現代 Monorepo（單一多專案儲存庫）跨端架構、共享通訊協定套件約束與安全急停（Watchdog）防護；(4) 邊緣 AI 視覺鏡頭整合、自走車全系統除錯與硬體在環（Hardware-in-the-Loop, HIL）實機閉環驗收。<br><br>教學方法採專案導向學習（PBL）與 PACE 協作框架（Prompt 提示設計、Audit 批判審計、Commit 微提交、Evaluate 雙層驗收），學生需從自然語言需求描述出發，批判審查 AI 生成之程式碼，並在真實物理賽道上反覆驗證軟硬體通訊與感測回饋。本課程旨在培養學生具備跨域系統整合思維、批判性代碼審計素養與解決複雜工程問題之實務信心。（483字） |
| **英文概要<br>(限2000字元)** | This course provides a comprehensive introduction and hands-on implementation to Physical AI and IoT cyber-physical system integration. In response to the transformative paradigm shift of generative AI and intelligent edge devices, this course adopts the cutting-edge "Vibe Coding" paradigm—software synthesis guided by natural language prompts and human code review—using an open-source robotic vehicle as the pedagogical vehicle to lower the cognitive barrier of traditional embedded systems.<br><br>The curriculum is structured into four progressive stages: (1) Toolchain setup and ESP32-C3 RISC-V core architecture; (2) Web Bluetooth (Web BLE) interactive mobile controller and differential drive kinematics; (3) Modern Monorepo architecture with type-safe shared protocol packages (`packages/protocol`) and safety fail-safe mechanisms (e.g., 500ms Watchdog and self-healing Wi-Fi); (4) Edge AI vision integration (ESP32-CAM), full-system cyber-physical debugging, and Hardware-in-the-Loop (HIL) real-device verification.<br><br>Employing Project-Based Learning (PBL) and the structured PACE pedagogical framework (Prompt, Audit, Commit, Evaluate), students act as system architects who guide AI agents with precise prompt constraints, audit generated firmware against hardware timing/pinout hazards, and conduct real-world track testing. Through continuous closed-loop feedback between physical dynamics and digital control, students develop high-order competencies in cross-domain system integration, code auditing, and robust problem-solving confidence for the physical AI era. |
